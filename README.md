## Overview

**CHWSI Explorer** is a self-contained, browser-based data story built by hand in **HTML, CSS and JavaScript** — no frameworks, no build step, no dependencies. It combines a scroll-driven narrative, an animated `<canvas>` globe, custom CSS theming and layout, interactive layer/year controls, and data charts drawn dynamically in JavaScript/SVG.

The entire experience — including every map raster — is embedded in **one `.html` file**, so it opens offline in any modern browser with a double-click.

The project presents the **Cryo-Hydrological Water Security Index (CHWSI)**: a composite surface that fuses cryosphere health and water stress to show that the Upper Ganga headwaters are **not running dry** — instead, the elevation at which water is generated is climbing steadily above the valleys where people actually live.

## The core finding

> Across six epochs, basin-mean water supply shows **no detectable trend** (R² = 0.09, p = 0.57) even though **a third of the glacier ice is gone**. What changed is *where* the water is made.

- **−34.6%** glacier area lost (3,304 km² in 2000 → 2,161 km² in 2024), and accelerating (41.5 → 56.2 km²/yr).
- Half the **demand** sits below **1,785 m**; half the **supply** is now generated below **2,664 m**.
- That **878 m vertical gap** between where water is made and where it is needed *is* the finding — a spatial mismatch, not a volumetric shortage.
- Water stress swings **non-monotonically** (2.31 → 0.99 in 2010 → 1.99 in 2024), so any two-epoch study would miss the dip entirely.

## Features

- **Scroll-driven zoom intro** — an animated canvas globe with a procedural starfield zooms from *Earth → India → Uttarakhand → Bhagirathi–Alaknanda → the basin* as you scroll.
- **Eight synchronised chapters** with reveal-on-scroll animations, chapter lighting and a fixed progress rail.
- **Interactive map explorer** — toggle layers (Glacier / Snow / Cryosphere Health Score) and epochs (2000–2024 / 2030 projection); click any map to open a full-screen lightbox.
- **Availability vs Demand comparison** — switch between the two near-mirror surfaces to see the north/high vs south/low spatial mismatch.
- **Charts drawn at runtime in SVG** — supply-vs-demand trend, stress trajectory, elevation-concentration (Lorenz-type) curves and a separation-vs-stress chart, all generated by JavaScript with no charting library.
- **Side-dot navigation** that tracks the active section.
- **`prefers-reduced-motion` support** — animations are disabled for users who request it.
- **Fully offline & portable** — all imagery is embedded as base64; no network calls, no server.

## Data & methods

- **Basin delineation** — HydroSHEDS Level-5 sub-basins (PFAF `452468` + `452469`), Bhagirathi–Alaknanda, 18,764 km², relief 446–7,804 m.
- **Cryosphere** — glacier and snow cover derived from NDSI; note that NDSI measures *area*, not mass, so the 34.6% figure is a **floor, not a ceiling**.
- **Hydrology** — a simplified, **SPHY-inspired** water-balance model producing mean water availability and demand surfaces.
- **Water stress** — computed as demand ÷ availability; the artefactual spike above ~4,500 m (no liquid water) is excluded.
- **Composite index** —
  ```
  CHWSI = 0.5 · CHS + 0.5 · (1 − Stress / 5)
  ```
  High = secure, low = vulnerable. Weights are equal and analyst-assigned.
- **Epochs modelled** — 2000, 2004, 2010, 2014, 2020, 2024; the 2030 layer is a *continuation of the trend*, not a forecast.

> ⚠️ **Scientific disclaimer.** The hydrological model is **simplified, uncalibrated and unvalidated** — no gauged discharge was available for the basin. Figures illustrate spatial and temporal *patterns*; they are not operational estimates. Please treat this as an exploratory visualisation and educational artefact rather than a validated hydrological product.

## Tech stack

- **HTML5** — semantic single-page structure.
- **CSS3** — custom properties (design tokens), CSS grid/flex layout, `backdrop-filter`, `IntersectionObserver`-driven transitions, and a fully hand-authored dark theme. No CSS framework.
- **JavaScript (vanilla)** — canvas globe + starfield animation loop, scroll orchestration, layer/epoch toggling, lightbox, and runtime SVG chart generation. No libraries.
- **SVG** — all analytical charts are constructed programmatically at runtime.
- **`<canvas>`** — the animated globe/zoom backdrop.
- **Embedded assets** — map rasters stored inline as base64 data URIs for true offline portability.

## Getting started

No install, no build, no server required.

```bash
# clone the repository
git clone https://github.com/<your-username>/chwsi-explorer.git
cd chwsi-explorer

# then simply open the file in any modern browser
```

Or just **double-click `CHWSI_Explorer.html`**.

> 💡 On mobile or a very old browser, allow the page a moment to render the embedded imagery. If you want a local server anyway:
> ```bash
> python3 -m http.server 8000   # then visit http://localhost:8000
> ```
